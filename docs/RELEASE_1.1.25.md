# sai 1.1.25

- Replaces the expandable composer with a stable, thin two-row design.
- The plus menu now exposes modes, installed Skills/plugins, URL tools,
  attachments, memories, and recent sessions.
- Permission and model/reasoning controls use focused hierarchical menus.
- The composer follows the Android IME and no longer remains behind it.
- The PTY terminal is a direct canvas: tap anywhere to focus the IME while the
  terminal's own echo remains the only visible command line.
- In-app and system-overlay task pets are mutually exclusive.
- Adds the responsive sai product website and unified GitHub Pages/Release
  automation for Android and Windows outputs.

The Android packages are test-signed development builds. Verify downloaded
files with `releases/SHA256SUMS-1.1.25.txt`.
