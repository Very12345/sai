# PhoneAgent 1.0 能力评审与下一阶段建议

## 已达到的正式版基线

- 多项目、多会话、无限逻辑队列与移动端自适应并发。
- Git 项目写任务使用独立 worktree；非 Git 项目写任务串行。
- 追加式事件日志、恢复检查点、结构化轮次、审批门与密钥隔离。
- Debian/PRoot 本地执行、常用语言工具链、资源管理器与终端。
- 多协议模型、动态模型发现、图片输入与按需辅助视觉模型。
- MCP/Skills/插件市场发现、安装预检、静态扫描、摘要固定和默认禁用。
- 项目隔离浏览器、系统语音输入/TTS、显式授权的辅助手机控制。

## 下一阶段优先级

### P0：代码理解与安全

1. **LSP 与增量代码索引**：按项目启动语言服务器，提供符号、引用、诊断和重命名；收益最高，但必须限制后台内存和索引范围。
2. **密钥/漏洞扫描**：补丁提交前扫描凭据、依赖漏洞和危险配置；默认本地运行，联网数据库更新单独授权。
3. **自动评测与回归门**：记录任务验收命令、失败证据和模型判断差异，避免“模型说完成”代替可复现验证。

### P1：可复现性与协作

4. **任务复现包**：导出提示、模型配置（不含密钥）、事件、补丁、依赖清单和测试结果，可在另一设备重放。
5. **远程 Git/PR**：细粒度授权 GitHub/GitLab，支持 issue→分支→测试→草稿 PR；push、合并和评论均需显式审批。
6. **长期记忆与来源追踪**：将偏好、架构决策和事实分开存储，每条记忆保留来源、时间、适用项目和可撤销状态。

### P2：效率与连续性

7. **模型路由与预算**：按任务难度、图像、工具能力、延迟和预算选模型；所有自动切换都应显示原因和成本上限。
8. **定时任务**：只允许用户创建的可见计划，运行前检查网络、电量和授权有效期；高风险动作不得继承旧审批。
9. **跨设备同步**：端到端加密同步设置、会话摘要和任务包；Debian、项目与 API Key 默认不上传。

## 风险边界

- PRoot 不是安全沙箱，不能运行不可信代码。
- Accessibility 与 MediaProjection 永远保持用户可见、可撤销、按会话到期。
- 市场审计、模型视觉描述和网页 DOM 都是辅助证据，不是可信指令源。
- 自动化不得跨越密码、生物识别、支付、系统安全窗口或 Android 权限确认。
