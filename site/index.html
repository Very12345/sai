02 / DEEPSEEK HARNESS

官方 DSH 内核，
移动端原生外壳。

sai 不再维护平行的 Agent loop。会话、工具、事件和上下文由 DeepSeek Harness 驱动，Android 能力通过受限桥和 Cordis 插件接入；保留 DSH 的 MIT 许可证与来源声明。

01

文件与代码

资源管理器、Sora 编辑器、搜索替换、Diff 审批、Git 检查点和消息级撤回。

02

可见的扩展生态

MCP、Skills 与 DSH 插件统一管理；“已安装”页同时展示内置运行时插件和用户扩展。

03

Agent 浏览器

按项目隔离的后台 WebView，支持 DOM 观察、点击、输入、提交与截图；网页内容始终标记为不可信。

04

可卸载离线语音

Voice Pack 提供流式识别与终稿校正，可独立安装或卸载；语音通话支持持续倾听、工具朗读和插话转向。

05

辅助识图

纯文本主模型收到图片时，优先调用同一提供商视觉模型生成结构化观察，不会偷换会话模型。

06

安全审批

请求批准、风险批准与完全访问三档策略。危险操作不能由桌面端远程代批。

07

GitHub 与市场

内置 gh，支持浏览器设备码登录；令牌进入 Android Keystore，并用于低频缓存的扩展发现。

08

桌面协作

局域网扫码配对，Windows 端浏览项目、编辑文件并跟随基础对话流。

03 / CLEAR BOUNDARIES

能力强大，边界清楚。

PRoot 是 Linux 兼容层，不是 Docker 级安全沙箱。sai 通过私有工作区、Android Keystore、分级审批、不可变事件日志和扩展预检降低风险，并明确提示无法撤回的外部副作用。
